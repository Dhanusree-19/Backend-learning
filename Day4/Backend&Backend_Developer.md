# Backend Basics

## What is Backend?

Backend is the server-side part of an application that handles **business logic, APIs, databases, authentication, and communication with other services**.

```text
User
  ↓
Frontend
  ↓
Backend
  ↓
Database
  ↓
Backend
  ↓
Frontend
  ↓
User
```

## What Does a Backend Developer Do?

A backend developer:

* Builds and maintains APIs
* Implements business logic
* Works with databases
* Handles authentication and authorization
* Validates and processes requests
* Integrates external services
* Writes tests
* Handles errors and security
* Fixes bugs and production issues
* Deploys and maintains backend applications

## Example

For an online shopping application:

```text
User → Add Product to Cart
            ↓
        API Request
            ↓
        Backend
            ↓
      Business Logic
            ↓
        Database
            ↓
       API Response
            ↓
         Frontend
```

The backend may:

1. Identify the user
2. Check whether the product exists
3. Check stock availability
4. Calculate the price
5. Apply business rules
6. Update the database
7. Return a response

## Key Idea

> **Backend development is about building the systems behind an application that process requests, apply business logic, manage data, and provide reliable services to the frontend.**
